# RapidScan Engine 2.0 (Standalone Reference)

This is a staged, AI-assisted scanning architecture.

## Pipeline

intake → preprocess → recognition → validation → enrichment → finalize → review

## Key Features

- non-blocking capture loop
- persistent queue
- duplicate rejection
- adaptive quality scoring
- confidence fusion
- AI escalation only when needed

## Purpose

This reference exists so the engine can be reused outside the main app.
